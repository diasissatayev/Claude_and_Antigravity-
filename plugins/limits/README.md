# limits: Claude, Codex and Gemini limits in one band

A mod that draws the 5-hour and weekly windows of your Claude, Codex (ChatGPT Plus) and Gemini
(Google AI Pro) subscriptions above the prompt, refreshed without spending any tokens, marks
providers that are not connected, and tells Claude which subscription to route work to.
`/limits` opens a pane with reset times; `/limits band` hides or shows the band.

See the [main README](../../README.md) for details.
